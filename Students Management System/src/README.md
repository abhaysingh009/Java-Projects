# 🎓 Student Management System (Java - Console Based)

## 📌 Overview

This is a simple **console-based Student Management System** developed in Java.
It allows users to manage student records using basic operations like adding, viewing, searching, and deleting students.

The project follows a clean structure using **separation of concerns**:

* Model layer (Student data)
* Data Access layer (DAO)
* Main execution layer

---

## 🚀 Features

* ➕ Add new student
* 📋 View all students
* 🔍 Search student by ID
* ❌ Delete student
* 🛠️ Simple console-based interface
